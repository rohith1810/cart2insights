# Statistical analysis

Significance level: alpha = 0.05. Generated by `src/stats_tests.py`.

## T-test: delivery delay and review score

**Question:** Do delayed orders receive significantly lower review scores than on-time orders?

- H0: Mean review score of delayed orders = mean review score of on-time orders.
- H1: Mean review score of delayed orders < mean review score of on-time orders.

**Test:** Independent two-sample t-test (Welch, one-sided)

**Assumption checks:**

- Independent groups: each order is either on time (88,953) or delayed (6,348).
- Normality: review scores are discrete (1-5), but both groups are large, so by the central limit theorem the sample means are approximately normal.
- Equal variances (Levene): p < 0.0001 -> unequal, so Welch t-test is used.
- Robustness check (Mann-Whitney U, no normality needed): p < 0.0001.

| Result | Value |
| --- | --- |
| Mean review (on time) | 4.292 |
| Mean review (delayed) | 2.272 |
| t statistic | -100.564 |
| p-value | < 0.0001 |
| Cohen's d | 1.712 |

**Decision:** Reject H0

**Business insight:** Delayed orders average 2.27 stars vs 4.29 for on-time orders (effect size d = 1.71). Delivery delay is linked to significantly lower satisfaction, so reducing delays should raise ratings.

## ANOVA: product category and order value

**Question:** Does the average order value differ significantly across product categories?

- H0: Mean order value is the same in all 10 categories.
- H1: At least one category has a different mean order value.

**Test:** One-way ANOVA across the 10 categories with the most orders

**Assumption checks:**

- Independent observations: each order belongs to one main category.
- Normality: order values are right-skewed, but each group is large, so the F-test is reasonably robust; Kruskal-Wallis is reported as a check.
- Equal variances (Levene): p < 0.0001 -> violated, so rely on Kruskal-Wallis as well.
- Kruskal-Wallis (non-parametric): p < 0.0001.

| Result | Value |
| --- | --- |
| F statistic | 189.423 |
| p-value | < 0.0001 |
| Eta squared | 0.0268 |
| Highest mean | watches_gifts (232.61) |
| Lowest mean | telephony (94.33) |

**Decision:** Reject H0

**Business insight:** Spending differs by category: watches gifts orders average 232.61 BRL vs 94.33 for telephony. Category explains 2.7% of the variation in order value, so pricing and promotions should be planned per category.

## Chi-square: payment method and order status

**Question:** Is there a significant association between payment method and order status?

- H0: Payment method and order status are independent.
- H1: Payment method and order status are associated.

**Test:** Chi-square test of independence

**Assumption checks:**

- Both variables are categorical and each order is counted once.
- Expected counts >= 5 in 100% of cells (rule of thumb: at least 80%).
- Order statuses grouped into Delivered, Canceled/unavailable and In progress/other so that no cell is too small.

| Result | Value |
| --- | --- |
| Chi-square | 154.479 |
| Degrees of freedom | 6 |
| p-value | < 0.0001 |
| Cramer's V | 0.0279 |

**Decision:** Reject H0

**Business insight:** Order outcome depends on payment method. voucher has the highest cancel/unavailable rate (3.62%). Cramer's V = 0.028, so the association is weak; follow up on slow or failed payments for that method.
